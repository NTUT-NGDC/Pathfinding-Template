# 題庫：追逐（給 AI 讀）

怎麼問看 [docs/ai_questions.md](../../docs/ai_questions.md)。第二輪挑 3～4 題，**1、2 題一定問**。粗體是題目，選項可以換成符合他們題材的說法；右邊兩欄不要唸出來。

一句話介紹（第一輪用）：**在房子裡躲敵人、拿東西、逃出去**（潛行、恐怖逃脫、小精靈、送貨都可以從這裡改）。

**「寫一點」的新東西放哪**：`examples/chase/features/名字/名字.tscn`（最上面是 Node2D），編輯器的「自製」就看得到，使用者自己放進關卡。就算是看不見的規則（例如「撿東西敵人變快」）也做成這種物件，畫一個小圖示，放在地圖上哪裡都可以。敵人特性放 `features/enemy_traits/`，敵人頁用勾的。

**分工**：一個人畫關卡，其他人做敵人的種類、物件的種類、新東西。

## 1. 玩家在裡面要做什麼？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 拿齊東西逃出去 | 寶物＋出口「全部」 | 編輯器 |
| 偷一個東西就跑，其他的可拿可不拿 | 出口「指定」勾那一個，或「數量」 | 編輯器 |
| 修好、打開某些東西再逃 | 任務點（名字、動詞、按幾秒），物件頁可以做新的一種 | 編輯器 |
| 把東西送到某個地方 | 寶物當貨物、出口當客人家 | 編輯器 |
| 把東西放回去 | 做新的目標（照 README 最下面「做新的目標」），放在 `features/名字/名字.tscn` | 寫一點 |
| 撐過一段時間 | `core/hud/timer_display.tscn` 倒數，時間到就贏 | 編輯器 |

## 2. 敵人怎麼發現你？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 用看的（看得到牠看哪裡） | 現成的；顯示視野錐 | 編輯器 |
| 用聽的，看不見（跑步、開門會被聽到） | 看多遠 0、勾「聽到就追」、聽力倍率 1.5～2 | 編輯器 |
| 又看又聽 | 現成的 | 編輯器 |
| 不會發現，只是一直巡邏，碰到就輸 | 看多遠 0、「有耳朵」不勾 | 編輯器 |

## 3. 被發現之後？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 一下子就追過來，很難逃 | 反應時間 0～0.5、追擊速度 200 以上（玩家走 110、跑 190） | 編輯器 |
| 有時間躲，躲好了牠會找一下再走 | 反應時間 1～1.5、追擊 130～150、放躲藏點和草叢 | 編輯器 |
| 抓到不會輸，送回起點 | 敵人「抓到目標就輸」不勾，接 `caught` 把玩家移回起點 | 寫一點 |
| 抓到扣血，三次才輸 | 同上，接 `caught` 扣 `core/hud/health_bar.tscn` | 寫一點 |

## 4. 有幾隻敵人、什麼個性？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 一隻很強的 | 殺手（追丟會放捕獸夾），數值調高 | 編輯器 |
| 好幾隻普通的，各自巡邏 | 守衛＋巡邏點 | 編輯器 |
| 每一隻個性不一樣 | 守衛（看得遠反應慢）、獵犬（聽力好跑得快）、殺手；再做一種笨的（「使用尋路」不勾，會卡牆） | 編輯器 |
| 敵人有特殊能力（尖叫叫同伴、衝刺、隱形……） | 新的敵人特性，照 `features/enemy_traits/trap_dropper.tscn` | 寫一點 |

## 5. 畫面是什麼感覺？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 很暗，只看得到身邊 | 黑暗半徑 120～160、暗度 0.95～1、關掉視野錐 | 編輯器 |
| 有點暗，看得到敵人在看哪 | 黑暗半徑 240、開視野錐（預設） | 編輯器 |
| 亮的，整張地圖都看得到 | 取消「有黑暗」 | 編輯器 |

## 6. 在什麼地方？

醫院、學校、鬼屋、超市、迷宮、辦公室……問要幾個房間、要不要一條長走廊。可以用文字先幫他們畫（`docs/ai_guide.md`「追逐的關卡也可以轉成文字」），再請他們用編輯器修。難度：編輯器。

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 躲進櫃子、床底 | 躲藏點 | 編輯器 |
| 丟東西引開敵人 | 瓶子，或規則頁「一開始幾個瓶子」 | 編輯器 |
| 鑰匙和上鎖的門 | 鑰匙、門「上鎖」同顏色 | 編輯器 |
| 草叢、玻璃、沼澤 | 地形 | 編輯器 |
| 小心地上的陷阱、警報 | 捕獸夾、警報 | 編輯器 |
| 新道具（隱形、加速、手電筒……） | 新物件 `features/名字/名字.tscn` | 寫一點 |

## 變化的點子（使用者要點子時挑 3 個，照他們的題材改）

| 點子 | 怎麼做 | 難度 |
| --- | --- | --- |
| 敵人看不見，但你跑步牠就衝過來 | 第 2 題用聽的 | 編輯器 |
| 每撿一個東西，敵人就變快一點 | 接寶物的 `completed`，改敵人 `chase_speed` | 寫一點 |
| 每撿一個東西，就多一隻敵人 | 接 `completed`，在某個點生一隻 `features/enemies/` 的 | 寫一點 |
| 每撿一個東西，就多一面牆 | 接 `completed`，`Walls` 加格子；`PathGrid.would_block()` 先看會不會堵死 | 寫一點 |
| 會響的地板、碎玻璃 | 新物件，玩家踩到 `SoundBus.emit_sound()` | 寫一點 |
| 你是來把東西放回去的小偷 | 第 1 題放回去 | 寫一點 |
| 敵人撿走你的東西，要搶回來 | 敵人特性＋寶物，要想清楚再做 | 寫一點（偏難） |
| 兩個人一起玩、連線 | — | 太大 → 改成「一個人控制，另一個人在旁邊看地圖報路」 |
| 很多層樓、很長的劇情 | — | 太大 → 兩三關串起來，每關開頭一句話 |

## 編輯器步驟（照抄給使用者，一次一段）

**打開編輯器**：在 Godot 左下的「檔案系統」雙擊 `examples/chase/map_editor/map_editor.tscn`，按 `F6`。上面有四頁：地圖、敵人、物件、規則。

**畫第一關**（地圖頁）

1. 按「新地圖」：會出現一間空房子，裡面已經有玩家和出口
2. 左下角打名字（英文，例如 hospital），按「存檔」
3. 按 `1` 到「地形」，選「牆」，左鍵畫、右鍵擦，隔出房間；「矩形」拖一下就是一道牆
4. 按 `4` 到「機關」，選「門」，點在牆上，會自己開一個缺口
5. 按 `3` 到「目標」，選「寶物」，點地板放幾個
6. 按「▶ 試玩」：走得到寶物、拿完走得出門口就成功。右上角「■ 停止試玩」回來

**放敵人和路線**（地圖頁）：按 `2` 到「角色」→ 選「敵人」，旁邊選哪一種 → 點地板放 → 點一下那隻敵人 → 選「巡邏點」→ 照順序點牠要走的地方

**做一種敵人**（敵人頁）：按「＋ 新敵人」→ 打名字 → 改右邊的數字，特性用勾的 → 按這一頁的「存檔」。之後地圖頁放敵人時就選得到

**出口、黑暗、玩家**：規則頁

**變成遊戲的關卡**：雙擊 `game_config.tres` → Levels 加一個元素 → 把 `examples/chase/levels/` 裡存的那一關拖進去
