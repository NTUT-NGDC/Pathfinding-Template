# 範例：追逐

在房子裡撿齊 3 個寶物、修好發電機，從出口逃出去。兩隻追逐 AI 會看、會聽、會繞過障礙物追過來；被碰到就輸。

- 打開 `levels/chase.tscn` 按 `F6`
- 操作：`WASD` 走（安靜）、`Shift` 跑（快但會發出聲音）、`E` 開門／躲進櫃子／撿東西、按住 `E` 修發電機（會發出聲音）、`1` 丟瓶子（落地的聲音會把敵人引過去）
- 除錯：`F1` 視野錐、`F2` 路徑、`F3` 追逐 AI 狀態、`F4` 聲音圈圈、`F5` 格子線

## 用到的積木

尋路地圖（PathGrid）、追逐 AI（ChaseAI，裡面有視野、耳朵、跟著路徑走）、聲音（SoundBus）

## 追逐編輯器（開發者用）

打開 `map_editor/map_editor.tscn` 按 `F6`。直接讀寫關卡場景 `levels/名稱.tscn`，**跟 Godot 可以輪流改**：手動加的節點（HUD、自己的東西）不會不見。

| 頁 | 可以做什麼 |
| --- | --- |
| 地圖 | 工具分五類，按 `1`～`5` 切換：**地形**（地板、磁磚、沼澤、牆、玻璃、草叢；畫筆、矩形、圓形、油漆桶）、**角色**（玩家、敵人、巡邏點）、**目標**（出口、寶物、鑰匙、任務點）、**機關**（門、躲藏點、捕獸夾、警報、瓶子）、**自製**（你自己做的物件）。左鍵畫或放、右鍵擦。敵人、任務點這些可以選「哪一種」。門和出口放在牆上會自己開一個缺口、轉對方向 |
| 地圖 → 右邊面板 | 用「選取」（或同一種工具）點物件：改**這一個**的數值、換一種、刪掉；「選取」可以拖著移動。黃色的是這一個自己改過的，「跟種類一樣」全部變回去 |
| 地圖 → 巡邏點 | 先點一隻敵人，再用「巡邏點」點地圖，照順序走；右鍵拿掉 |
| 敵人 | 有哪幾種敵人（附殺手、守衛、獵犬）：視野、速度、反應、聽力、開關、顏色，勾特性（放捕獸夾）。改一種，地圖上這一種全部跟著改 |
| 物件 | 任務點（附發電機、電腦、保險箱）、捕獸夾、警報、躲藏點、自己做的物件，各可以有好幾種。改法跟敵人一樣 |
| 規則 | 出口什麼時候開（全部、指定、數量、一開始就開）、玩家的速度和瓶子、黑暗、鏡頭 |

- **種類**：「基本○○」是底，不能改，按「複製成新○○」拿來改。敵人存在 `features/enemies/`，其他存在 `features/名字/kinds/`，都是一般場景，拖進關卡也能用。**一種改了，用到它的每一關都會變**；只想改一隻，在地圖上點它改
- **刪掉一種**：清單下面的「刪掉」按兩次。地圖上或別的關卡有用到就不能刪（會說是哪裡）；刪掉的在資源回收桶
- **讓 AI 畫關卡**：關卡可以轉成文字再轉回來（命令看 [docs/ai_guide.md](../../docs/ai_guide.md)），地形、物件、巡邏點都在；AI 畫完，用編輯器打開再修
- **自己做特性**：照 `features/enemy_traits/trap_dropper.tscn`（一個場景＋一支腳本，`trait_name()` 是名字、`description()` 是說明），放進 `features/enemy_traits/` 就會出現在「敵人」頁
- 「新地圖」＝一間空房子，打名字按「存檔」就是新的一關，拖進 `game_config.tres` 的 Levels 就能串關。「▶ 試玩」在編輯器裡直接玩
- 地圖比一個畫面大會自動打勾「跟著玩家」
- **自己做的物件**放在 `features/名字/名字.tscn`（最上面是 Node2D），會出現在「自製」，也可以在「物件」頁做好幾種；`@export` 的欄位自動變成右邊的表單，名字讀上面那行 `##` 註解
- 存檔時 Godot 如果開著那一關，回到 Godot 會問要不要重新載入，選「重新載入」
- 存檔是寫進專案資料夾，只有在 Godot 編輯器裡按 F6 才能存

## 不寫程式可以改什麼

用編輯器最快；要直接在 Godot 裡改的話：

| 想改 | 怎麼改 |
| --- | --- |
| 房子的樣子 | 點 `Walls` 畫牆（深灰）、玻璃（看得到過不來）、草叢（過得去看不到）；`Floor` 畫地板、沼澤（走起來慢） |
| 敵人的個性 | 點 `ChaseAI`／`Guard`，改檢查器的「個性」（視野、速度、反應時間……）和「開關」 |
| 敵人的巡邏路線 | 拖 `ChaseAI` 底下的 `PatrolPoint`；想多一個點就在它底下加 Marker2D |
| 多一隻敵人 | 把 `features/enemies/` 裡的（殺手、守衛、獵犬）拖進來，或最基本的 `addons/ngdc_pathfinding/chase_ai/chase_ai.tscn` |
| 寶物、鑰匙 | 拖 `features/pickup/pickup.tscn` 進來，選「寶物」或鑰匙顏色；「算進出口條件」打勾的才算 |
| 任務點（發電機、電腦、保險箱、拉桿……） | 拖 `features/task_point/task_point.tscn` 進來，改名字、動詞（修理／駭入／拉下）、要按住幾秒（0＝按一下）、聲音多大、顏色 |
| 出口什麼時候開 | 點 `Exit`，「開門條件」選：全部（打勾的目標都完成）、指定（把寶物、任務點拖進「指定目標」）、數量（完成任意幾個）、一開始就開 |
| 鏡頭 | 點 `FollowCamera`：「跟隨」打勾會跟著玩家（再把 Zoom 調成 2 比較看得出來）；「邊界」的大小、偏移決定鏡頭最多看到哪裡（編輯器裡的黃框） |
| 門 | 拖 `features/door/door.tscn` 到牆的缺口，可以上鎖（要同顏色的鑰匙） |
| 躲藏點 | 拖 `features/hiding_spot/hiding_spot.tscn`（櫃子、床） |
| 捕獸夾 | 拖 `features/trap/trap.tscn`：踩到夾住幾秒、發出聲音；可以調秒數、聲音、AI 會不會繞開（按 `F2` 看 AI 繞路）、夾完會不會消失 |
| 敵人追丟時放夾子 | 編輯器的「敵人」頁勾「放捕獸夾」；或把 `features/enemy_traits/trap_dropper.tscn` 拖到追逐 AI 底下（範例裡紅色那隻有）；可以改哪個狀態放、最多幾個、放下的夾子踩過會不會消失 |
| 警報（壓力板） | 拖 `features/alarm/alarm.tscn`：踩到發出很大的聲音，附近的敵人都會過來；可以調聲音、冷卻、只響一次、隱形 |
| 瓶子（誘餌） | 拖 `features/throwable/bottle.tscn` 讓玩家撿；丟多遠、聲音多大、一開始有幾個在 `Player` 的「瓶子」那一組 |
| 恐怖還是公平 | `Darkness` 的半徑、多暗（不要黑暗就刪掉它）；追逐 AI 的「顯示視野錐」 |

## 可以改成

- **潛行**：把出口換成「偷到東西不被發現」，追逐 AI 的反應時間調長
- **恐怖逃脫**：黑暗開很暗、關掉視野錐、殺手靠聽的
- **小精靈**：地圖改成迷宮、寶物放滿、四隻追逐 AI 用不同個性
- **外送**：寶物變成要送的東西，出口變成客人家

## 給會寫程式的人：做新的目標

出口和左上角的計數只認「目標」：在 `objectives` 群組裡、有 `required`（算不算進出口條件）、`is_done`（完成了沒）、`category`（分類名稱）三個屬性、完成時發出 `completed(objective)` signal 的節點。照這個做，例如「踩到就完成的機關」，出口和計數就會自動算到它。參考 `features/task_point/scripts/task_point.gd`。
