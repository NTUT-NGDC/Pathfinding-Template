# 題庫：塔防（給 AI 讀）

怎麼問看 [docs/ai_questions.md](../../docs/ai_questions.md)。第二輪挑 3～4 題，**1、2 題一定問**。粗體是題目，選項可以換成符合他們題材的說法；右邊兩欄不要唸出來。

一句話介紹（第一輪用）：**蓋塔擋住一波一波走過來的怪**（殭屍圍城、守護東西都可以從這裡改）。

**「寫一點」的新東西放哪**：怪物掛件 `features/enemy_traits/`（怪物頁用勾的）、砲塔掛件 `features/tower_traits/`；其他的放 `examples/tower_defense/features/名字/`，由畫地圖的人放進關卡場景。

**分工**：一個人畫地圖、一個人排波次、一個人做怪、一個人做塔，各自的檔案。

## 1. 怪怎麼走過來？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 你蓋的東西會擋路，怪要繞（迷宮） | 「塔可以蓋在」勾空地（參考 `maps/default.tres`） | 編輯器 |
| 怪走固定的路，你蓋在路旁邊 | 整片畫高地再把路擦出來，「塔可以蓋在」只勾高地、「牆」都不勾（參考 `maps/fixed_route.tres`） | 編輯器 |
| 從好幾個方向來 | 多放幾個出怪口（參考 `maps/two_gates.tres`） | 編輯器 |
| 用飛的，直線過來 | 怪勾「會飛」 | 編輯器 |

## 2. 你在守什麼？被碰到會怎樣？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 一個基地，被碰 10 次就輸 | 現成的；血量在 `BaseGroup` | 編輯器 |
| 好幾個，一個被打爆就輸 | 多放基地，`BaseGroup` 的 Mode | 編輯器 |
| 好幾個，全部被打爆才輸 | 同上 | 編輯器 |
| 一群會動的東西（羊、居民） | 基地要會動 | 太大 → 放好幾個不會動的基地，畫成羊 |

## 3. 有沒有牆？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 有，怪會把牆打破 | 現成的；`features/builder/block.tscn` 的 Max Health、Break Cost | 編輯器 |
| 有，打不破，一定要繞 | 同上，Breakable 不勾 | 編輯器 |
| 沒有牆，塔就是牆 | 「牆可以蓋在」都不勾 | 編輯器 |
| 好幾種門窗，怪會挑弱的打 | 照 `block.tscn` 另存幾種不同血量、Break Cost，加進 `Builder` | 寫一點 |

## 4. 有哪些怪？（可以複選）

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 快但很脆 | 快怪 | 編輯器 |
| 慢但很硬 | 坦克（厚血、裝甲） | 編輯器 |
| 會飛 | 飛行怪 | 編輯器 |
| 打死會分裂 | 分裂怪 | 編輯器 |
| 會補血 | 治療怪 | 編輯器 |
| 新的能力（隱形、衝刺、放屁變慢……） | 怪物掛件，照 `features/enemy_traits/` | 寫一點 |

## 5. 有哪些塔？（可以複選）

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 普通、緩速、範圍、連射 | 現成的，改名字、顏色、數字（`features/tower/`） | 編輯器 |
| 新的效果（燒、毒、定住、推開……） | 砲塔掛件，照 `features/tower_traits/` | 寫一點 |
| 不會打、但有別的用處（賺錢、補牆） | 新的塔 | 寫一點 |

## 6. 一場多久、多難？

| 選項 | 怎麼做 | 難度 |
| --- | --- | --- |
| 3 分鐘，輕鬆 | 波次頁 4 波，開場等久一點 | 編輯器 |
| 5 分鐘，要想一下 | 波次頁 6 波（預設） | 編輯器 |
| 很難，要一直試 | 起始金錢調少、後面的波加厚血 | 編輯器 |
| 好幾關 | 每張地圖「做成關卡」，拖進 `game_config.tres` | 編輯器 |

## 變化的點子（使用者要點子時挑 3 個，照他們的題材改）

| 點子 | 怎麼做 | 難度 |
| --- | --- | --- |
| 塔本身就是牆 | 第 3 題 | 編輯器 |
| 全部是會飛的怪，只能靠位置 | 第 4 題 | 編輯器 |
| 怪會挑最弱的門打 | 第 3 題 | 寫一點 |
| 花錢修牆 | 點壞掉一半的牆補血，放 `features/repair/` | 寫一點 |
| 塔會餓，要花錢餵 | 塔掛件，每隔幾秒扣錢，沒錢就停 | 寫一點 |
| 打死的怪變成路障 | 怪物掛件，接 `died`，`PathGrid.set_blocked()`，先 `would_block()` | 寫一點 |
| 每一波地形會變 | 波次開始時改格子，先 `would_block()` | 寫一點 |
| 你自己也在場上跑來跑去打 | 主角＋攻擊，跟塔防是兩套 | 太大 → 做成「滑鼠點怪也能打一下」（寫一點） |

## 編輯器步驟（照抄給使用者，一次一段）

**打開編輯器**：在 Godot 左下的「檔案系統」雙擊 `examples/tower_defense/map_editor/map_editor.tscn`，按 `F6`。上面有三頁：地圖、波次、怪物。

**畫第一張地圖**（地圖頁）

1. 按「新地圖」
2. 選「出怪口」點一格（怪從這裡出來），選「基地」點另一邊的一格（你要守的）；右鍵拿掉
3. 選「岩石」左鍵畫、右鍵擦，擺一些擋路的東西
4. 最下面的「塔可以蓋在」「牆可以蓋在」勾要的地面（不要牆就都不勾）
5. 左下角打名字（英文，例如 map_kai），按「存檔」
6. 按「▶ 試玩」：下面選塔、左鍵蓋，怪會繞路走過來就成功。右上角「■ 停止試玩」回來

**固定的路**：選「高地」用「油漆桶」整片塗滿 → 用右鍵把路擦出來 → 「塔可以蓋在」只勾高地

**排波次**（波次頁）：按「＋ 新的一波」→ 選什麼怪、幾隻、隔幾秒；同一波要混別種就按「＋ 同時出」→ 打名字、存檔

**做一種怪**（怪物頁）：選一隻按「複製成新怪」→ 打名字、改數字、勾掛件 → 按「存檔」。之後波次頁就選得到

**變成遊戲的關卡**：地圖和波次都存檔 → 按最上面的「做成關卡」→ 雙擊 `game_config.tres` → Levels 加一個元素 → 把 `examples/tower_defense/levels/` 裡那一關拖進去
