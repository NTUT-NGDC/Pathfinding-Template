# 範例：塔防

怪從出怪口出來，走向基地（出怪口、基地都可以有好幾個）。用牆和塔排出迷宮，怪會即時改路，繞太遠就把牆打破；基地被摸 10 次就輸，撐過 6 波就贏。

- 打開 `levels/tower_defense.tscn` 按 `F6`
- 操作：下面的按鈕（或按數字鍵 `1`～`9`）選要蓋什麼：牆、塔、緩速塔、範圍塔、連射塔；滑鼠左鍵蓋、右鍵拆（退一半）；打死怪加錢
- 左鍵點蓋好的塔＝升級（滑鼠移上去看價格；塔下面的小黃點是等級）
- 蓋不了的格子會變紅，旁邊寫原因：會把路堵死、錢不夠、岩石上不能蓋、塔只能蓋在高地上……
- 選塔的時候會先畫出射程；滑鼠移到蓋好的塔上也看得到射程
- 右上角 `▶ 1×` 切換倍速（1×、2×、3×）
- 鏡頭：`WASD`／方向鍵、滑鼠移到畫面邊緣、按住中鍵拖曳移動；滾輪縮放
- 除錯：`F2` 路徑、`F5` 格子線

## 用到的積木

尋路地圖（PathGrid：`set_blocked`、`set_cost`、`would_block`）、生怪器（Spawner）、小怪（Walker）、跟著路徑走（地圖變了自動改路）

範例自己的東西在 `features/`：地圖（map）、蓋東西（builder）、塔（tower）、怪物掛件（enemy_traits）、砲塔掛件（tower_traits）、做好的怪（enemies）、基地（base）、畫面上的東西（hud）。

## 塔防編輯器（開發者用）

打開 `map_editor/map_editor.tscn` 按 `F6`。上面有三頁：**地圖、波次、怪物**，共用上一步／下一步和「▶ 試玩」（用現在畫的地圖＋現在排的波次）。「存檔」變黃、多一個＊，表示有東西還沒存。

### 地圖頁

| 想做 | 怎麼做 |
| --- | --- |
| 畫岩石（怪不能走） | 選「岩石」，左鍵畫、右鍵擦；滾輪調筆刷大小 |
| 畫沼澤（怪走得慢） | 選「沼澤」，一樣左鍵畫、右鍵擦 |
| 畫高地（怪不能走） | 選「高地」。固定路線型的塔防：整片畫高地，再把路擦出來 |
| 換畫法 | 「畫筆」一筆一筆畫；「矩形」「圓形」拖曳畫出形狀；「油漆桶」把點到的那一整塊相連的地形換掉（右鍵：擦掉那一塊） |
| 哪裡可以蓋塔、蓋牆 | 最下面一排「塔可以蓋在」「牆可以蓋在」：空地、沼澤、高地、岩石各自勾（牆都不勾＝沒有牆的按鈕） |
| 上一步、下一步 | `Ctrl`＋`Z`、`Ctrl`＋`Y`（或按「↶」「↷」） |
| 放出怪口、基地 | 選「出怪口」或「基地」，左鍵點一格放一個（可以放好幾個），右鍵拿掉 |
| 地圖大小 | 「寬」「高」改格數（左上角不動，畫好的保留） |
| 移動、縮放畫面 | `WASD`／方向鍵、滑鼠到邊緣、中鍵拖曳；`Ctrl`＋滾輪縮放（滾輪是筆刷大小） |
| 存檔 | 下面打地圖名稱，按「存檔」→ 存成 `maps/名稱.tres` |
| 讀檔 | 「讀檔…」清單裡選一張 |
| 試玩 | 按「▶ 試玩」就在編輯器裡直接玩這張地圖（不換場景）；按右上角的「■ 停止試玩」（或暫停選單、勝敗畫面的「回地圖編輯器」）回來繼續畫。編輯時沒有暫停選單，試玩時才有，地圖還在，記得存檔 |
| 關卡換地圖 | 打開 `levels/tower_defense.tscn`，點 `MapLoader`，把 `maps/` 裡的地圖拖進 Map |

範例地圖：`maps/default.tres`（迷宮型，一個出怪口、一個基地）、`maps/two_gates.tres`（迷宮型，兩個出怪口、兩個基地）、`maps/fixed_route.tres`（固定路線型：彎彎的路，塔只能蓋在路旁的高地，不能蓋牆）。

> 存檔是寫進專案資料夾，只有在 Godot 編輯器裡按 F6 才能存。存完回到 Godot 編輯器，`maps/` 裡就會出現新的檔案。

### 波次頁

一列是一種怪，一波可以混好幾種一起出。存成 `waves/名稱.tres`，跟地圖分開，可以換著配。

| 想做 | 怎麼做 |
| --- | --- |
| 多一波、複製、換順序 | 「＋ 新的一波」「複製」「▲▼」 |
| 一波混好幾種怪 | 那一波按「＋ 同時出」 |
| 出什麼怪、幾隻、隔幾秒、從哪個出怪口 | 直接改那一列（出怪口的號碼跟地圖上的一樣） |
| 這一波的血量、速度 | 填數字；`0`＝用怪自己的。右邊的 `→` 是掛件算完的**實際數字**（例如填 6、厚血 ×3 → 18，裝甲減半 → 要打 36） |
| 第一波前等幾秒、兩波之間等幾秒 | 「開場等」「兩波之間等」（出完最後一隻才開始算） |
| 只測後面的波次 | 「▶ 從這波試玩」（前面幾波的錢會先給） |
| 關卡換波次 | 打開 `levels/tower_defense.tscn`，點 `Spawner`，把 `waves/` 裡的檔案拖進 Wave Table |

### 怪物頁

改怪的名字、顏色、數值，**掛件用勾的**，旁邊有預覽和實際數字。存成 `features/enemies/` 裡的一般場景（繼承 `walker.tscn`＋掛件），要在 Godot 裡開來改也可以。普通怪是尋路積木本身，不能改，按「複製成新怪」拿來改。要刪掉一隻怪，在 Godot 的檔案系統刪。

> 怪物存檔時如果 Godot 編輯器正開著那個場景，回到編輯器會問要不要重新載入，選「重新載入」。

## 迷宮型、固定路線型

哪種地面可以蓋塔、蓋牆寫在地圖裡（地圖編輯器最下面那排勾選，或在檢查器點地圖的 `Tower Ground`、`Wall Ground`），換地圖就換玩法：

| 玩法 | 塔可以蓋在 | 牆可以蓋在 | 怪怎麼走 |
| --- | --- | --- | --- |
| 迷宮型（`default`、`two_gates`） | 空地、沼澤、高地 | 空地、沼澤 | 空地、沼澤上的塔會擋路，怪即時繞路（塔不能把路堵死）；牆也擋路，但怪可以打破 |
| 固定路線型（`fixed_route`） | 高地 | （都不勾） | 塔蓋在路旁的高地，不擋路；怪走固定的路 |

蓋在空地、沼澤會擋路；高地、岩石本來就不能走，蓋在上面不影響怪的路。

## 打得壞的牆

牆登記成尋路地圖的障礙物：**走得過去，但很貴**。A* 自己會比較「繞路」和「拆牆」哪個便宜，所以同樣一面牆，缺口近就繞、缺口遠就拆。走到牆前面會停下來打，好幾隻一起打比較快；打破之後大家重新找路。

- 可以用牆把路完全堵死（怪會拆）；塔打不壞，所以塔不能把路堵死
- 會飛的怪不理牆
- 這一關的尋路地圖設成「不斜走」，不然怪會從斜放的兩面牆中間鑽過去

| 想改（打開 `features/builder/block.tscn`） | 欄位 |
| --- | --- |
| 牆打不壞（以前的玩法：一定要繞路、不能堵死） | Breakable 取消打勾 |
| 牆多硬 | Max Health |
| 怪多不想拆牆 | Break Cost：拆牆等於多走幾格，越大越願意繞路 |
| 怪打牆多快 | 怪的 Wall Damage：每秒扣幾滴血 |

## 升級

點塔，在檢查器的「升級」：最高等級（1＝不能升級）、每升一級傷害／射程／攻速變幾倍、升級價格的倍率。

升級價＝塔現在的價值 ×（三個倍率相乘 － 1）× 升級價格的倍率。升級之後價值也跟著變高，所以越後面越貴。例如塔 4 元：升 Lv2 要 3 元、升 Lv3 要 4 元。跟多蓋一座差不多划算，好處是省位置。拆掉退總共花的一半。

掛件的數字不會跟著升（範圍傷害會，因為照塔的傷害算）；想讓自己做的掛件跟著升，接塔的 `upgraded(等級)`。

## 好幾個出怪口、好幾個基地

每隻怪出生時走向**路的成本最低**的基地（沼澤、要拆的牆都算）（會飛的怪看直線距離）。蓋塔時，每個出怪口都要還走得到至少一個基地，不然蓋不下去。

| 想要 | 怎麼設 |
| --- | --- |
| 怪輪流從每個出怪口出來 | 什麼都不用改（預設） |
| 這一波從某個出怪口出來 | 編輯器的波次頁，那一列的「出怪口」選第幾個 |
| 每個出怪口各自一份波次表 | 多放幾個 `Spawner`（`addons/ngdc_pathfinding/spawner/spawner.tscn`），都拖進 `MapLoader` 的 Spawners；第 1 個出怪口給第 1 個生怪器，以此類推。全部打完才算贏 |
| 基地共用一條血（預設） | `BaseGroup` 的 Mode 選「共用一條血」，血量看 Shared Max Health |
| 每個基地各自的血，一個被打爆就輸 | Mode 選「各自的血：一個被打爆就輸」，血量看 `features/base/base.tscn` 的 Max Health |
| 全部基地被打爆才輸 | Mode 選「各自的血：全部被打爆才輸」：被打爆的基地消失，怪改去別的基地 |

## 怪物掛件、砲塔掛件

跟工作坊的機制卡一樣：**拖到怪物（或塔）底下當子節點**就生效，可以掛好幾個。放錯地方會有黃色驚嘆號。

| 怪物掛件（`features/enemy_traits/`） | 效果 |
| --- | --- |
| `fast` 加速 | 速度 ×1.6 |
| `tank` 厚血 | 血量 ×3、身體變大 |
| `armor` 裝甲 | 受到的傷害減半 |
| `flying` 會飛 | 不尋路，直線飛向基地，牆擋不住（拿來對比「會尋路的怪」） |
| `split` 分裂 | 死掉分成 2 隻小的 |
| `healer` 治療 | 每 2 秒幫附近的怪補血 |

| 砲塔掛件（`features/tower_traits/`） | 效果 |
| --- | --- |
| `slow` 緩速 | 打到的怪慢一半，持續 1.5 秒 |
| `splash` 範圍傷害 | 旁邊的怪也扣一半的血（範圍塔改成 0.75） |
| `multi_shot` 多重射擊 | 一次多打 2 隻 |

做好的怪在 `features/enemies/`（快怪、坦克、飛行怪、分裂怪、治療怪），做好的塔在 `features/tower/`（塔、緩速塔、範圍塔、連射塔）。數字都可以在掛件的檢查器改。

## 不寫程式可以改什麼

| 想改 | 怎麼改 |
| --- | --- |
| 地圖 | 用地圖編輯器畫，再把地圖拖進 `MapLoader` 的 Map |
| 鏡頭 | 點 `PanCamera`：要不要鍵盤／滑鼠邊緣／中鍵移動、移動速度、縮放範圍 |
| 波次 | 用編輯器的「波次」頁（或點 `Spawner` 的 Wave Table，在檢查器改） |
| 怪、新的怪 | 用編輯器的「怪物」頁（或在 Godot 打開 `features/enemies/` 的場景） |
| 新的塔 | 打開 `features/tower/tower.tscn` 另存新檔，掛上砲塔掛件，改名字（Display Name）、價錢、射程、傷害、攻速、顏色；再加進 `Builder` 的 Tower Scenes |
| 塔先打誰 | 點塔的 Target Priority：離塔最近／最接近基地／血最多／血最少 |
| 牆的價錢、起始金錢 | `Builder` 的 Wall Cost；`HUD/Info/Money` 的 Score |
| 基地血量 | `Base` 的 Max Health |
| 沼澤多難走 | `MapLoader` 的 Swamp Cost |
| 倍速有哪幾段 | `HUD/SpeedButton` 的 Speeds |
| 勝負 | `Spawner` 的「打完就贏」；`Base` 扣光就輸 |

## 可以改成

- **塔防，但塔本身就是牆**：拿掉牆，只能蓋塔
- **殭屍圍城**：基地換成房子，做幾種不同血量、Break Cost 的牆當門和窗，殭屍會挑弱的打
- **飛行怪大軍**：大部分是會飛的怪，牆沒用，只能靠塔的位置

## 給會寫程式的人：做新的掛件

- 怪物掛件：`extends EnemyTrait`，在 `apply()` 裡改 `walker` 的數值（`speed`、`max_health`、`damage_taken_multiplier`……），或接 `walker.died`；想在編輯器的怪物頁顯示中文，覆寫 `trait_name()`、`labels()`
- 砲塔掛件：`extends TowerTrait`，覆寫 `apply()`（改 `tower` 的數值）或 `on_hit(敵人, 傷害)`（每打到一隻怪做什麼）
