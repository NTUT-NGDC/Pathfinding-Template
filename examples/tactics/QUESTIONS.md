# 題庫：戰棋（給 AI 讀）

怎麼問看 [docs/ai_questions.md](../../docs/ai_questions.md)。第二輪挑 3～4 題，**1、2 題一定問**。粗體是題目，選項可以換成符合他們題材的說法；右邊兩欄不要唸出來。

一句話介紹（第一輪用）：**帶一隊人，輪流走格子打架**（自動打、自己下、邊探索邊打都可以）。

**「寫一點」的新東西放哪**：棋子特性 `features/unit_traits/`，棋子頁用勾的。

**分工**：地圖、小隊、規則在同一個檔案，一個人做；其他人做棋子（一隻一個檔案）、新特性；起始隊伍全部關卡共用一份，由一個人改。

## 編輯器步驟（照抄給使用者，一次一段）

**打開編輯器**：在 Godot 左下的「檔案系統」雙擊 `examples/tactics/map_editor/map_editor.tscn`，按 `F6`。上面有五頁：地圖、小隊、棋子、規則、隊伍。

**畫第一關**（地圖頁）。我方的人不是在地圖上放的，是從「隊伍」頁來的；地圖上只放「起點」

1. 按「新地圖」，左下角打名字（英文，例如 map_amy）
2. 按 `1` 到「地形」，選「牆」左鍵畫、右鍵擦
3. 按 `2` 到「我方」，選「起點」，點我方要出來的地方（只有一個）
4. 按 `3` 到「敵人」，旁邊選哪一隊、哪一種棋子，點地圖放幾隻
5. 按「存檔」，再按「▶ 試玩」：看得到自己的隊伍和敵人就成功。右上角「■ 停止試玩」回來

**一開始就下棋**：「小隊」頁勾「一開始就開打」→「規則」頁「戰鬥一開始」選回合制（想看自動打就選自動）

**巡邏**（探索的玩法才要）：地圖頁按 `3` → 選那一隊 → 選「巡邏點」照順序點

**我方有誰**：「隊伍」頁改起始隊伍，按那一頁自己的存檔（每一關共用，一個人改）。只有這一關要不一樣：「規則」頁放固定的隊伍

**做一種棋子**（棋子頁）：選一隻按「複製成新棋子」→ 改名字、身上的字、顏色、數字，特性用勾的 → 按這一頁的「存檔」。之後地圖頁、隊伍頁就選得到

**怎樣算贏、骰子、人數**：規則頁

**變成遊戲的關卡**：地圖存檔 → 按最上面的「做成關卡」→ 雙擊 `game_config.tres` → Levels 加一個元素 → 把 `examples/tactics/levels/` 裡那一關拖進去
