# 範例：戰棋

我方（藍）和敵方（紅）輪流走。點我方棋子會亮出走得到的格子（沼澤走一格算 3），點格子走過去；走到敵人旁邊會打它一下。敵人全滅就贏，我方全滅就輸。

- 打開 `levels/tactics.tscn` 按 `F6`
- 操作：滑鼠左鍵點棋子、點格子；右鍵取消；全部走完或按「結束回合」換敵方
- 敵方回合：每個敵人往最近的我方走（最簡單的 AI）

## 用到的積木

尋路地圖（PathGrid：不斜走、沼澤成本 3）、移動範圍（MoveRange：BFS＋成本）、跟著路徑走

範例自己的小腳本在 `features/`：棋子（unit）、回合（turn）。

## 不寫程式可以改什麼

| 想改 | 怎麼改 |
| --- | --- |
| 地圖 | 點 `Walls` 畫牆、`Floor` 畫沼澤 |
| 棋子 | 拖 `features/unit/unit.tscn` 進來，選隊伍、移動力、血量、攻擊力 |
| 可以斜走 | `PathGrid` 的 Diagonal |
| 範圍的顏色 | `MoveRange` 的顏色 |

## 可以改成

- **戰棋，但地形每回合會變**：每回合用 `PathGrid.set_blocked()`／`set_cost()` 改幾格
- **自走棋**：拿掉我方回合，兩邊都用敵方 AI 自己走
- **小隊指揮**：拿掉回合，改用點擊移動（`addons/ngdc_pathfinding/click_move/click_mover.tscn`）
- **經營**：棋子變客人，「走向最近的我方」改成「走向最近的空位」
