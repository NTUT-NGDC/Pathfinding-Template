# 範例：戰棋

帶著一支隊伍在地圖上探索，躲開（或偷襲）巡邏的敵人小隊。被發現就進入戰鬥：先布陣，再照速度輪流行動，可以讓電腦自動打，也可以自己一步一步下。

- 打開 `levels/tactics.tscn` 按 `F6`（探索＋三隊敵人）
- 其他兩關：`levels/boss.tscn`（打倒首領就贏，可以繞過其他小隊）、`levels/arena.tscn`（純戰棋，一開始就布陣、回合制）
- 除錯：`F1` 視野錐、`F2` 路徑、`F5` 格子線

## 怎麼玩

| 階段 | 操作 |
| --- | --- |
| 編隊 | 出發前從自己的**隊伍池**選誰要去、排順序（第一個是隊長）、選陣形，按「出發」。按「重來」會記得上次選的 |
| 探索 | `WASD` 走，或用**滑鼠左鍵**點地上自己繞路走過去（按住＝跟著滑鼠、點寶箱＝走過去搜），隊友照陣形自己跟上；碰到物資會撿起來；`E` 紮營休息（花一份物資、等幾秒、全隊回血），在寶箱旁邊按 `E` 是搜括、同伴旁邊是招募；都會被敵人注意到而中斷 |
| 隊伍 | `Q`、點頭像、點棋子＝換人控制；`Tab` 整隊／分開；`1`～`4` 換陣形（一列、橫排、箭頭、圍一圈），誰站哪照隊伍順序 |
| 被發現 | 敵人頭上 `?` 是在懷疑，`!` 就開打。從背後碰到還沒發現你的敵人＝**偷襲**，第一輪我方全部先動 |
| 布陣 | 時間暫停。點自己的棋子 → 點藍色格子擺放（點自己人＝交換），右邊勾誰上場，選自動或回合制，按「開始戰鬥」。箭頭先告訴你誰打算打誰 |
| 戰鬥 | 上場人數預設不限（規則頁可以改）。每一輪照**速度**由快到慢，每隻動一次，上面是行動順序 |
| 自動 | 點敵人＝**指定目標**（再點一次取消，暫停中、布陣時也可以）：打得到就一定打它，這一輪打不到就先打別人，誰都打不到就往它走；補師還是先救快倒的 |
| 回合制 | 藍色可以走、紅框可以打（綠框可以補血）。直接點紅框的敵人會自己走過去打，指著時先標出會站在哪；點自己＝**留在原地**。`空白鍵` 待命、右鍵反悔 |
| 隨時 | 「自動」開關（下一步就生效）、倍速 1×／2×／3×、暫停（暫停時可以看每一隻的數值）、「意圖」開關、「日誌」（右上，誰打誰、扣多少、骰到幾、哪個特性發動，可以往回捲） |

**意圖箭頭**：紅色是敵人、藍色是自動的我方、綠色是補血；實線＝這一輪打得到，虛線＝還打不到、正往它靠近。照現在的狀況猜的，有人動了就重算。指著一隻，牠、牠的目標、打算打牠的會亮起來，其他變淡，連要走的路一起畫。

滑鼠移到棋子上：左下角看數值和特性，紅色格子是它這一回合打得到的地方；輪到你時指著敵人，會先告訴你扣多少血。

打贏之後血不會自己回復；倒下的人用 1 滴血站起來，要靠營地物資休息。物資在地上、寶箱裡，有的小隊打倒了會掉，誰都可以撿。上場的全部倒下就輸。

## 隊伍池

玩家的隊伍跟著玩家走，每一關都從同一個池子挑，每一關開始都滿血。

- **起始隊伍**：剛開始玩就有的人，在編輯器的「隊伍」頁改，存成 `party_pool.tres`
- **招募**：地圖頁用「同伴」放在路上，走到旁邊按 `E` 就加入，當場能用；**過關之後**才會留在隊伍池，輸了或重來要重新招募
- **過關獎勵**：規則頁設定過關後加入誰，只給一次
- **固定隊伍**：規則頁放了固定的隊伍，這一關就只用那些人（教學關、純戰棋，例如 `arena`）
- 加入的人存在玩家的電腦（`user://`）。要從頭測：「隊伍」頁的「清掉玩家存檔」。試玩不會動到存檔
- 「倒下的人離隊」只算那一關，過關後會回到隊伍池

## 整隊走、分開走

- **整隊**：你控制的人帶頭，其他人照陣形跟；敵人只看帶頭的
- **分開**：只有你控制的人會動，其他人站在原地，可以派一個人去引開、探路、開寶箱。**每個人都會被看到**
- **分開時被發現**：被發現的人附近 10 格內（走路距離）的隊友一起布陣；更遠的**趕來支援**，照尋路的距離和移動力算幾輪後到，從戰場邊緣進場。場上的人全倒就輸，支援還沒到也算
- 分開時紮營只有附近的人回血；「走到目標格」要隊長（隊伍第一隻）走到

## 用到的積木

尋路地圖（PathGrid）、移動範圍（MoveRange：每隻有自己的成本規則、`path_to()`）、跟著路徑走（PathFollower：`follow()` 跟隨、`go_to()` 巡邏、`walk()` 照算好的路走）、視野（VisionSensor）

範例自己的東西在 `features/`：隊伍池（party_pool）、地圖（map）、探索（explore：隊伍、敵人小隊、物資、寶箱）、戰鬥（battle：輪流、電腦）、棋子（unit）、做好的職業（units）、特性（unit_traits）、畫面（hud）。

## 戰棋編輯器（開發者用）

打開 `map_editor/map_editor.tscn` 按 `F6`。上面有五頁：**地圖、小隊、棋子、規則、隊伍**，共用上一步／下一步和「▶ 試玩」。地圖、小隊、規則存在同一個檔案（`maps/名稱.tres`），棋子各自一個場景。「存檔」變黃、多一個＊，表示有東西還沒存。

| 頁 | 可以做什麼 |
| --- | --- |
| 地圖 | 左鍵畫、右鍵擦：牆、沼澤、森林、高地，工具有畫筆、矩形、圓形、油漆桶；放起點、目標、物資、寶箱（旁邊設裡面有幾份）、同伴；選一隊和一種棋子放**敵人**，再放**巡邏點**；改大小。滾輪調筆刷、`Ctrl`＋滾輪縮放、`WASD`／中鍵移動畫面 |
| 小隊 | 看多遠、視野角度、隊友看多遠（或只有帶頭的有視野）、反應時間、巡邏方式和速度、支援距離（別隊開打時多近會加入）、打倒之後掉幾份物資、首領、一開始就開打 |
| 棋子 | 數值、身上的字、顏色、個性，**特性用勾的**，有預覽；新棋子、複製成新棋子（存到 `features/units/`） |
| 規則 | 這一關固定的隊伍（空的＝用隊伍池）、過關獎勵、出發前要不要編隊、最多帶幾人（0＝全部）、最多上場幾隻（0＝不限）、陣形、能不能分開走、幾格內一起布陣、怎樣算贏、一開始自動或回合制、要不要擲骰子、營地物資、紮營回復多少、倒下會不會站起來 |
| 隊伍 | 起始隊伍（每一關共用，有自己的存檔鈕）、清掉玩家存檔 |

> 存檔是寫進專案資料夾，只有在 Godot 編輯器裡按 F6 才能存。分工時地圖取自己的名字，才不會互相蓋掉。

**做成關卡、串關**：地圖存檔之後按「做成關卡」→ 產生 `levels/地圖名.tscn`（繼承 `tactics.tscn`，只換地圖），再拖進 `game_config.tres` 的 Levels。

## 敵人小隊怎麼巡邏

- **有巡邏點**：全隊照地圖上擺的相對位置排成**隊形**一起走，落後的會加快；窄的地方會擠過去再散開
- **沒有巡邏點**：每一隻站在原地各自張望
- **每一隻都有視野**，誰看到都算，警戒值整隊共用。想簡單一點就勾「只有帶頭的有視野」

## 地形

跟塔防一樣用程式畫，邊緣是圓滑的，不用找素材。打開「**對齊格子**」就一格一格畫、邊緣是直的；兩種可以混在同一張圖（`tactics` 的牆是方的、`boss` 的岩壁是圓的、`arena` 全部對齊格子）。規則看格子**中心**在哪種地形裡。

| 地形 | 走進去花 | 效果 |
| --- | --- | --- |
| 空地 | 1 | |
| 沼澤 | 3 | |
| 森林 | 2 | 站在裡面防禦 +1；**擋視線**，探索時可以躲 |
| 高地 | 2 | 站在上面遠程多打一格 |
| 牆 | 不能走 | 擋視線、擋遠程 |

數字在 `features/map/scripts/tactics_map.gd` 最上面的 `KIND_COSTS`、`KIND_DEFENSE`。

## 職業和特性

扣血＝攻擊 － 對方的防禦（最少 1）。做好的職業在 `features/units/`：

| 職業 | 特色 | 特性 |
| --- | --- | --- |
| 劍士 | 平均 | 反擊 |
| 弓箭手 | 打 2～3 格，旁邊打不到 | |
| 重裝兵 | 血厚、慢 | 守護、攔截 |
| 騎兵 | 走得遠 | 突擊 |
| 法師 | 打 1～2 格 | 範圍攻擊 |
| 補師 | 補血 | 治療 |
| 飛行兵 | 走得遠 | 飛行 |
| 刺客 | 最快、打最痛、很脆 | 吸血 |
| 大槌兵 | 慢、打得痛 | 擊退 |
| 蜥蜴人 | 沼澤裡很強 | 沼澤行者 |

特性在 `features/unit_traits/`，跟塔防的掛件一樣**拖到棋子底下**（或在編輯器勾）就生效，可以掛好幾個：

| 跟尋路有關 | 效果 | 跟戰鬥有關 | 效果 |
| --- | --- | --- | --- |
| `flying` 飛行 | 不管地形，可以飛過牆和敵人；探索時也直線飛過岩石（敵人的視野照樣被岩石擋住） | `counter` 反擊 | 被打會還手 |
| `swamp_walker` 沼澤行者 | 難走的地形像平地 | `healer` 治療 | 可以幫自己人補血 |
| `intercept` 攔截 | 敵人走到旁邊就得停 | `area` 範圍攻擊 | 打到的敵人旁邊也扣血 |
| `charge` 突擊 | 走越遠打越痛 | `knockback` 擊退 | 把敵人推開，撞到東西多扣血 |
| | | `guard` 守護 | 旁邊的自己人少受傷 |
| | | `lifesteal` 吸血 | 打人時補自己的血 |

**骰子**（規則頁，預設關）：每次攻擊擲一顆六面骰，1 失手、6 傷害加倍，日誌會寫骰到幾。

**個性**（電腦怎麼決定，自動戰鬥的我方也會用）：衝鋒＝打最近的；守衛＝有人走進打得到的範圍才動（我方自動時不會發呆）；挑最弱的＝打血最少的；保持距離＝打得到就站最遠。

## 不寫程式可以改什麼

| 想改 | 怎麼改 |
| --- | --- |
| 地圖、敵人、巡邏、規則 | 用編輯器 |
| 職業、新職業 | 編輯器的「棋子」頁，或在 Godot 打開 `features/units/` 的場景 |
| 隊長走多快、隊友跟多近、紮營幾秒、搜寶箱幾秒 | 關卡的 `Party` |
| 布陣範圍、戰場大小、動作快慢、打幾輪算輸、右邊留多寬 | 關卡的 `Battle` |
| 探索時的鏡頭大小 | 關卡的 `TacticsLevel` 的 Camera Zoom |
| 有哪幾段倍速 | 關卡的 `HUD` 的 Speeds |

## 可以改成

- **純戰棋**：小隊勾「一開始就開打」，規則選回合制（參考 `arena`）
- **自走棋**：純戰棋＋規則選自動，玩家只決定布陣
- **潛行**：勝利條件選「走到目標格」，敵人放很強，能不打就不打
- **TRPG**：規則勾擲骰子；想加對話、裝備、經驗值、技能、背包都可以自己接，這裡故意不做，先把走哪裡、打誰看懂
- **恐怖**：反應時間 0、支援距離調大，被一隊看到全部都來
- **小隊指揮、經營**：拿掉戰鬥，改用點擊移動（`addons/ngdc_pathfinding/click_move/click_mover.tscn`）

## 給會寫程式的人：做新的特性

`extends UnitTrait`（`features/unit_traits/scripts/unit_trait.gd`），覆寫需要的函式就好：`step_cost()`（走路的成本）、`modify_attack()`、`modify_taken()`、`after_attack()`、`after_hit()`、`turn_started()`……要在編輯器顯示中文，覆寫 `trait_name()`、`description()`、`labels()`。扣血、補血、推人用 `battle.hurt(誰, 多少, 為什麼)`、`battle.mend(誰, 多少, 為什麼)`、`battle.slide()`；想在日誌多寫一行用 `battle.note()`（名字用 `battle.name_of()` 會上色）。改到傷害的特性會自動寫進日誌。

電腦怎麼算分數在 `features/battle/scripts/battle_ai.gd` 的 `_score()`，想加新的個性改這裡。
